## 怎么使用

1. **先按效果找分类**：例如按钮、输入框、弹窗、加载状态或页面区块。
2. **打开具体条目**：了解这个效果通常叫什么，以及适合放在什么场景。
3. **描述你想要的变化**：说清外观、内容、状态和操作，再把提示词交给 Vibe Coding 工具。

## 一个好用的界面描述

写需求时，可以依次说明 **组件名称、外观结构、交互行为和状态变化**。例如：“做一个下拉选择器，默认显示当前选项；点击后展开选项列表；选择后关闭列表并更新已选内容。”

不必一开始就知道专业名词。先描述你看到的效果和希望发生的变化，再通过对应条目逐步补齐表达。
